# 💈 Jhon Suarez Barber Shop — Web Oficial

> Web de lujo con efecto 3D scrolling para **Jhon Suarez Barber Shop**, barbería premium en Rota (Cádiz).

[![Deploy Status](https://img.shields.io/github/deployments/TU-USUARIO/jhon-suarez-barber-shop/github-pages?label=Deploy&logo=github)](https://TU-USUARIO.github.io/jhon-suarez-barber-shop/)

## 🌐 Live URL
**https://TU-USUARIO.github.io/jhon-suarez-barber-shop/**

## 🛠️ Stack
- HTML5 + CSS3 + Vanilla JS (sin frameworks)
- Google Fonts: Bebas Neue + Playfair Display + Inter
- Particles canvas propio (sin librerías externas)
- GitHub Pages + Cloudflare CDN

## 📁 Estructura
```
index.html            # Página principal
assets/
  css/main.css        # Estilos
  js/main.js          # Lógica principal
  js/particles.js     # Animación hero
  images/             # Fotos del local y portafolio
data/
  services.json       # Catálogo de servicios (editable)
.github/workflows/
  deploy.yml          # Auto-deploy a GitHub Pages
```

## ✏️ Cómo actualizar servicios
Edita el archivo `data/services.json` y haz push. Los cambios se reflejan automáticamente.
